地基雷达监测报告生成器 Mobile V1
=================================

功能
- 读取“面数据”Excel：位移工作表，第1行为表头，第2行开始为时间序列。
- 读取“点数据”Excel：位移工作表，第1行为表头，第2~4行为X/Y/Z，第5行开始为时间序列。
- 自动取两份文件共同时间点。
- 生成6小时报告。
- 生成24小时报告，并可选择对比周期。
- 复制/分享报告、保存TXT。
- 导出24小时Excel对比表（“面”“点”两个工作表）。

重要兼容处理
雷达平台导出的示例 XLSX 工作表 dimension 自报为 A1，但实际有 P 列、约1.9万行数据。
手机版读取时使用 SheetJS 的 nodim:true，强制按实际单元格重新计算范围，避免只读到 A1。

推荐部署方式（PWA）
1. 将本文件夹全部文件原样上传到任意 HTTPS 静态网站空间。
2. 用 iPhone Safari 打开 index.html 对应网址。
3. Safari 分享按钮 -> “添加到主屏幕”。
4. 以后从主屏幕“雷达报告”图标打开。

首次使用
首次打开请联网，以加载官方 SheetJS 0.20.3 浏览器组件。Service Worker 会尝试缓存已使用资源，之后可提高离线可用性。

数据隐私
应用没有上传接口。用户选中的 Excel 由浏览器前端 JavaScript 读取和计算。
