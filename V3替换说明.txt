# V3 替换说明

V3 对应最新上传的 `wjz shibao_zhong.py`。

与 V2 相比，最重要的变化是数据源从 2 个变为 4 个：

- 短时面（小时级）→ 6 小时报告
- 短时点（小时级）→ 6 小时报告
- 长时面（日级）→ 24 小时 / 周报
- 长时点（日级）→ 24 小时 / 周报

同时，V3 按最新 Python 逻辑更新了：
- 6 小时报告的总累积位移从长时数据中获取；
- 24 小时报告使用 15:00 节点；
- 周报使用周五 15:00 节点；
- 24h/7d 对比计算；
- 24h 对比表和周报对比表。

## 替换 GitHub Pages

如果 V2 已经部署成功：

1. 不需要新建仓库。
2. 不需要修改 Pages 地址。
3. 将 V3 文件直接覆盖原仓库根目录同名文件。
4. 保持 `main` + `/(root)`。
5. 等 Actions 中 `pages build and deployment` 变成绿色。
6. Safari 刷新网页即可。

本目录包含 `.nojekyll`，用于让 GitHub Pages 按静态文件直接发布。
